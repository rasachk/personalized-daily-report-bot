# Daily Report Helper Bot

Daily Report Helper is a Telegram bot that sends daily reminders and reports based on user subscriptions.

Users can subscribe to different services and receive automated daily updates at their chosen time.

## Features

Currently implemented services:
- Weather Forecast

Planned services:
- Currency rates
- Sports updates
- Personal reminders
- More daily report services

## How it works

1. User creates a new reminder in the bot.
2. Selects a service (e.g., Weather Forecast).
3. Enters service required details (e.g., Location).
4. Sets daily reminder time.
5. Bot sends daily updates automatically.
